# 🍔 Food Munch – Responsive Restaurant Website

## 📌 Project Overview
Food Munch is a responsive restaurant website built using HTML, CSS, Bootstrap, and Flexbox. The project focuses on creating a modern UI and ensuring responsiveness across different devices.

## 🚀 Features
- Fully responsive design (mobile, tablet, desktop)
- Built using Bootstrap grid and CSS Flexbox
- Media queries for different screen sizes
- Clean and user-friendly interface

## 🛠️ Tech Stack
- HTML5
- CSS3
- Bootstrap
- Flexbox
- Media Queries
